# Evaluation protocol

The case labels were authored before the frozen main run. `cases.json` is separate from the 11-document retrieval corpus. Run `python -m unittest discover -s tests -v` for the independent offline tests. Start both local model APIs, then run `python -m evaluation.run_evaluation`. This makes 84 sequential requests: 20 answerable plus 6 unanswerable questions across closed-book LLM, basic RAG, and full-agent modes, followed by 6 full-agent tool/auditor cases. Every case is checkpointed to `results/`; `--resume` preserves prior responses and refuses changed code/corpus/cases/model hashes. Requests are never silently retried.

Run all commands from the project root (the folder containing `app.py` and `requirements.txt`), using the activated project environment or `.venv\Scripts\python.exe` in place of `python`. Setup installs GGUF files in `runtime/models`; the runner fingerprints that folder by default. For a separate validation asset directory, set the environment variable `EVIDENCEDESK_RUNTIME_DIR` to the directory containing its `models` subfolder. This changes metadata discovery only; the model API URLs remain the application settings. When available, the runtime manifest and its exact pinned model revisions are recorded alongside checks against the actual files.

The supplied `results/` directory is the historical measured run and must remain intact. For a fresh reproduction, first work in a copy of the project and rename that copy's `evaluation/results` to `evaluation/results_original`, then run the module command above. The runner refuses to overwrite existing results. Use `--resume` only to continue an interrupted run with unchanged fingerprints; it is not a new independent run.

The full agent can rewrite its search query, so this comparison concerns end-to-end variants rather than a causal audit-only ablation. Generated and delivered claims are checked independently. Source-ID membership and exact normalized contiguous quotation are **mechanical validity**, not semantic support or truth. The denominator is all claims, including invalid ones; zero-claim validity is undefined. Coverage and abstention denominators are reported alongside validity. Closed-book source validity is not applicable because that variant has no sources.

Keyword matching uses predeclared OR alternatives within each group and AND across groups. It is a lexical coverage heuristic, **not semantic answer accuracy**. `human_review_blank.csv` intentionally contains no invented human labels. Independent original-query dense Recall@3 is measured over all 20 answerable questions, with the thresholded figure reported separately. Four external routing cases report predicted route, attempted tool dispatch, and successful upstream completion separately; two other cases check the automatically invoked auditor, not LLM selection of that node.

`auditor_challenges.json` includes a deliberately false claim paired with a real quotation. It should mechanically pass, demonstrating the auditor's scope limitation. Models, quantization files, SHA-256 hashes, code/corpus/case hashes, inference settings, runtime release, timestamps, complete responses, cache statuses, errors, and actual latency are preserved. The study is one run on an authored tiny corpus, with no statistical-significance, broad-generalization, or state-of-the-art claim.
